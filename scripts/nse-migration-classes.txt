# M007B migration effect-shape classification (M005E residual: 72 ungated + 25 advisory = 97 entries).
#
# Format: `<path> <CLASS> <rationale>`
#
# Classes:
# - BrokerCompatibleTcp: blocking connect-style TCP; plain read/write (or TLS-over-Read/Write,
#   or internal TcpStream plumbing); tokio use, if any, is bridge-only (block_on/Handle::current/
#   spawn_blocking around sync logic or `*_async` Lua entries). Migrated in M007B by rewiring to
#   broker_tcp_connect/send/receive (or BrokeredTcpStream where Read/Write is required).
# - BrokerCompatibleUdpConnected: connected-UDP semantics fitting NseUdpSocket (bind+connect, no
#   send_to/recv_from/broadcast). Migrated via broker_udp_connect/send/receive.
# - AsyncDirectIo: structural async requiring a separate bounded bridge (tokio::spawn, channels,
#   select!, multi-task pipelines). EMPTY in M007B: audit found no structural async; every tokio
#   use is bridge-only. Class retained as vocabulary per plan §3.
# - UnconnectedDatagram: send_to/recv_from/broadcast/multicast semantics not represented by the
#   connected UDP provider. Explicitly manual-only (out of scope: UDP provider redesign).
# - NativeHandleEscape: external crate requires concrete std::net::TcpStream (ssh2::Session).
#   Explicitly manual-only (out of scope: native socket escape).
# - RawPacketOrInterface: operation outside the TCP/UDP provider contract. Explicitly manual-only.
# - PublicCompatibilityApi: src/public_api/api.rs public sync surface. Kept manual/native unless
#   separately redesigned (out of scope per plan §6).
#
# Guard: scripts/check-boundaries.sh (M007B section) asserts every M005E pin entry appears exactly
# once here, and every BrokerCompatible* entry is promoted (no direct socket remains) by closure.
# Unknown/unlisted classification is a stop condition (plan §3).
