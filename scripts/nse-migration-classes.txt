# M007B migration effect-shape classification — FINAL (corrective pass).
#
# Baseline: the M005E residual inventory of 97 files (72 ungated +
# 25 advisory). Every one of those 97 paths keeps exactly one final
# class here. Two additional paths were discovered by the M007B
# corrective scan (direct DNS resolution was not covered by the M005E
# socket-only scan) and are classified at the end.
#
# Format: `<path> <CLASS> <rationale>`
#
# Classes (effect shape, not migration status):
# - BrokerCompatibleTcp: blocking connect-style TCP; plain read/write
#   (or TLS-over-Read/Write, or internal TcpStream plumbing); any tokio
#   use is bridge-only. Fully migrated to
#   `broker_tcp_connect`/`broker_send`/`broker_receive` and
#   `BrokeredTcpStream`. These files MUST NOT appear in
#   scripts/nse-specialized-{ungated,advisory}.txt.
# - BrokerCompatibleUdpConnected: connected-UDP semantics (bind+connect,
#   no send_to/recv_from/broadcast) fitting the UDP provider contract.
#   Migrated via `broker_udp_connect`.
# - ProviderBackedDns: direct DNS resolution that fits the injected
#   `NseDnsProvider` contract. Migrated via `broker_dns_lookup`.
# - AsyncDirectIo: structural async needing a separate bounded bridge
#   (tokio::spawn, channels, select!, multi-task pipelines). EMPTY: the
#   audit found no structural async; every tokio use was bridge-only.
#   Retained as vocabulary.
# - UnconnectedDatagram: send_to/recv_from/broadcast/multicast semantics
#   that the connected-UDP provider cannot represent. Manual-only
#   (out of scope: UDP provider redesign).
# - NativeHandleEscape: an external crate requires a concrete
#   std::net::TcpStream (ssh2::Session). Manual-only (out of scope: native
#   socket escape).
# - RawPacketOrInterface: operation outside the TCP/UDP provider
#   contract. Manual-only.
# - PublicCompatibilityApi: src/public_api/api.rs public sync surface.
#   Manual/native unless separately redesigned (out of scope).
#
# Invariants enforced by scripts/check-boundaries.sh:
#   - every path here is a real source file and appears exactly once;
#   - every current residual file has a class here;
#   - no `BrokerCompatible*` / `ProviderBackedDns` path may still hold a
#     direct host network effect;
#   - provider/broker infrastructure is never listed here.
